# Bottom navigation 3D icons

Generated with the built-in image generation tool for this project, then exported as transparent 128 × 128 WebP assets. All four images are bundled locally and included in the service-worker shell cache. Combined payload: approximately 15 KB. IconScout's home icon catalogue was reviewed as a style suggestion; these are original generated assets, not downloaded IconScout assets.

| Button | Asset | Subject prompt |
| --- | --- | --- |
| Home | dist/assets/nav-home.webp | A small coral-red roof house with warm ivory walls, a single mint-green door and one window |
| Subjects | dist/assets/nav-subjects.webp | A single open mint-green hardcover book with thick ivory pages |
| PYQs | dist/assets/nav-pyqs.webp | A small stack of ivory exam papers with amber edge and three embossed amber horizontal answer lines, no letters |
| Quiz | dist/assets/nav-quiz.webp | A violet-purple trophy cup with two warm gold handles on a small violet pedestal |

Shared generation direction: one isolated centered object on true transparency; polished soft clay 3D; rounded bevels, ceramic highlights, soft ambient occlusion; readable silhouette at 30px; three-quarter front view, slight top view; studio lighting upper left; no text, logos, watermark, floor, background tile or decorative objects.

Validation: all four assets loaded in browser; Home, Subjects, PYQs and Quiz navigation works; visual review in light and dark themes; existing syntax checks and 8 tests pass. Mobile sizing follows the existing bottom bar breakpoints (29px icons below 520px, 26px below 360px). Actual phone review remains pending.
