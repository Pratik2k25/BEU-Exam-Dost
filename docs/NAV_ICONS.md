# Navigation 3D icons

The four mobile dock icons were generated with the built-in image generation tool, then exported as transparent 128 × 128 WebP assets. The desktop-only Planner and Notifications icons are hand-drawn transparent SVGs with matching rounded, dimensional shading. All assets are bundled locally and included in the service-worker shell cache. IconScout's home icon catalogue was reviewed as a style suggestion; these are original assets, not downloaded IconScout assets.

| Button | Asset | Subject prompt |
| --- | --- | --- |
| Home | dist/assets/nav-home.webp | A small coral-red roof house with warm ivory walls, a single mint-green door and one window |
| Subjects | dist/assets/nav-subjects.webp | A single open mint-green hardcover book with thick ivory pages |
| PYQs | dist/assets/nav-pyqs.webp | A small stack of ivory exam papers with amber edge and three embossed amber horizontal answer lines, no letters |
| Quiz | dist/assets/nav-quiz.webp | A violet-purple trophy cup with two warm gold handles on a small violet pedestal |
| PYQ Quiz / Master Quiz | dist/assets/nav-quiz.webp | Reuses the same quiz icon for both quiz destinations |
| Planner | dist/assets/nav-planner.svg | A dimensional green study calendar with warm ivory pages, amber binding rings and simple check marks |
| Notifications | dist/assets/nav-notifications.svg | A dimensional amber bell with a coral clapper and restrained mint alert accents |

Shared generation direction: one isolated centered object on true transparency; polished soft clay 3D; rounded bevels, ceramic highlights, soft ambient occlusion; readable silhouette at 30px; three-quarter front view, slight top view; studio lighting upper left; no text, logos, watermark, floor, background tile or decorative objects.

Validation: the original four WebP assets remain the mobile dock art. Desktop Planner and Notifications use matching transparent SVG artwork, while both quiz destinations share the same 3D trophy. New assets are included in the service-worker shell cache. The brand mark sits independently above the desktop rail. Actual phone review remains pending.
