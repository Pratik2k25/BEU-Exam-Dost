# Exam Dost Implementation Plan

Goal: Turn the approved mobile UI into an offline-ready, account-free review PWA.
Architecture: Buildless ES modules; separate replaceable demo content from local user state. Shared navigation and design tokens preserve all approved screen rules.
Tech: HTML, CSS, JavaScript, service worker, Web App Manifest, Node test runner.

- [x] Core: test scoring, elapsed timing, unit/year counts, planner scheduling and backup validation before implementation.
- [x] UI: setup, home, subjects, subject units, topic checklist, PYQ index/detail with analysis table, quiz type/subjects/papers, timed quiz, serial result review, planner, profile, preferences, backup and installation.
- [x] Persistence: versioned local data; preserve attempts on exit, track cumulative per-question active time, protect imports and escape user text.
- [x] PWA: local assets, manifest, offline navigation/cache, install handling and update notice.
- [x] QA: core tests, mobile/desktop browser journey, no-overlap checks, offline reload, package and publish private review.

Constraints: Demo data is labelled throughout. No login or network transmission of profile records; collection endpoint and analytics intentionally unconfigured until provider selection. APK remains unavailable until independently packaged. Coral Back pill and global nav share a safe-area bottom offset. Active quiz Back means previous question; Exit handles leaving. Main quiz chooses type before subject. Official content is supplied later.
Review focus: malformed backups, empty content, reload mid-quiz, expired quiz timer, small-screen fixed controls.

See docs/REVIEW.md for actual verification and remaining device-specific limits.
